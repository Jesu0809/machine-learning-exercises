Decision Tree: Concepts

The classification algorithm assigned to this group, explained before its implementation on the Application page.

Name and definition

A Decision Tree is a supervised model that classifies an observation by asking a sequence of yes/no questions about its features until it reaches a leaf node that holds a class.

How the algorithm works

During training it searches, at each node, for the feature and cut-off value that best separate the classes (measured with Gini impurity), splits the data in two, and repeats on each branch until a stopping rule is met — here a maximum depth of 4.

Types of problems it can solve

Binary and multi-class classification, and also regression. It works with numeric and categorical features and does not need feature scaling.

Main characteristics

  • A flowchart of if / else rules over the features.
  • Every prediction can be traced from the root to a single leaf.
  • No feature scaling or normalisation required.
  • Produces a ranking of feature importance.

Advantages

  • Easy to read, explain and visualise.
  • Fast to train and to predict.
  • Captures non-linear relationships between features and class.
  • Handles features on different scales without preprocessing.

Limitations

  • A deep tree overfits: it memorises the training data and generalises poorly.
  • Small changes in the data can produce a very different tree.
  • Usually less accurate than ensembles such as Random Forest.

Example of a real-world classification problem

Deciding whether to approve or deny a credit card application from the applicant's annual income, debt-to-income ratio, credit history length and number of open credit lines — exactly the problem implemented on the Application page.

The trained tree

Each box is a question about one feature; following the branches from the top to a leaf gives the predicted class.
