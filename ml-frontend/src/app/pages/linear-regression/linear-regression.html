Linear Regression

Linear regression is one of the most fundamental algorithms in machine learning and statistics. It models the relationship between an independent variable (the input, such as years of work experience) and a dependent variable (the output, such as salary) by fitting a straight line through the observed data points. The core idea is that as the input increases or decreases, the output changes at a constant, predictable rate, which is represented by the slope of the line.

This technique is widely used because it is simple, fast, and easy to interpret. It serves as a baseline model for prediction tasks across many fields, such as estimating salaries based on experience, forecasting sales based on advertising spend, predicting house prices based on square footage, or analyzing how one factor influences another. Whenever there is a reasonable assumption that two variables move together in a roughly linear way, linear regression provides a quick and reliable way to quantify that relationship and make predictions on new, unseen data.

Mathematically, the model finds the line that best fits the data by minimizing the difference between the predicted values and the actual observed values, typically using a method called Ordinary Least Squares. This means the algorithm searches for the slope and intercept that minimize the sum of the squared errors (the vertical distances between each data point and the line). Once trained, the resulting equation, in the form y = mx + b, can be used to plug in a new value of x (years of experience) and instantly obtain a predicted value of y (estimated salary), which is exactly what the calculator below does.
