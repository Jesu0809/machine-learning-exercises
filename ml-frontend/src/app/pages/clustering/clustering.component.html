K-Means Clustering: Application

Segment bank credit applicants into risk groups without using the approval outcome.

1. Problem Context

Instead of predicting whether an application is approved (a supervised problem, solved earlier with a Decision Tree), here we ask an unsupervised question: do credit applicants naturally group into distinct profiles based only on their financial features? K-Means finds k groups by repeatedly assigning each applicant to the nearest centroid and recomputing centroids, without ever seeing the actual approval decision.

3. Choosing k: the Elbow Method

Inertia (within-cluster sum of squares) keeps dropping as k grows. The "elbow" — the point where adding more clusters stops helping much — is around k=3, which is what the model uses below.

4. K-Means Model

Pipeline: CSV dataset → pandas → 4 numeric features → StandardScaler → KMeans(n_clusters=3).fit_predict() → each applicant labeled with a cluster. Scaling matters here because income (tens of thousands) and debt-to-income ratio (a percentage) live on very different scales.
