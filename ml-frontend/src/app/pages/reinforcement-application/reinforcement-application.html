Reinforcement Learning: Find the Exit

A Q-Learning agent learns, by trial and error, how to cross a 10×10 maze that also contains danger zones.

1. Problem Context

The agent (A) starts in the top-left cell of a 10×10 maze and must reach the target (T) in the bottom-right cell. It has no map: it only knows its current position and, after every move, the reward it received. Three wall segments jut in from alternating edges of the grid, each leaving a gap on the opposite side, so the agent has to zigzag through them instead of taking a straight line. Ten cells are marked as danger zones: the agent can still walk into them, but doing so costs far more than a normal move, so a good policy avoids them whenever a safer route exists.

Reinforcement learning is used here because there is no dataset of correct answers, only a sequence of decisions that the agent has to learn from experience, balancing the shortest route against the risk of crossing a danger zone.

ParameterWhy this value
Episodes The maze has 79 non-wall states besides the target, with 4 actions each. In our runs every episode reaches the target from episode 111 onward, and the average episode length settles at about 42 moves after episode 500, so 1000 episodes leaves margin.
Discount γ The shortest safe route takes 40 moves, so the +{{ info.rewards.goal }} at the end has to stay visible from the start: 0.95 keeps distant rewards relevant without making every state look equally good.
ε start, floor and decay The agent begins fully random (1.0) because it knows nothing. Multiplying by 0.995 after every episode reaches the 0.05 floor around episode 600, so the last 400 episodes are mostly spent refining the best route while still trying a random move 5% of the time.
Learning rate Each partial_fit() call moves a Q-value 10% of the way toward its new target. With 0.01 the final evaluation does not reach the target after 1000 episodes, and 0.03 learns more slowly (909 successful episodes instead of 954); with 0.3 or 0.5 the agent settles on a shorter route through a danger zone that ends with a lower total reward (8 instead of 11).
Update every The agent stores its last {{ info.training_config.update_every }} transitions and partial_fit() learns from them in the order they happened. Calling it once per step made training take about 27 seconds on a laptop and longer than the server allows on Render; grouping {{ info.training_config.update_every }} transitions learns the same route in about 2 seconds.
Max steps / episode A random walk in a 10×10 maze rarely finds the exit in a few dozen moves, so 300 steps gives early episodes room to reach the target while still cutting off an agent that wanders in circles.
