Linear Regression: Concepts

Before using the calculator, here are the fundamental ideas behind Simple Linear Regression.

Linear Regression is a supervised Machine Learning algorithm that models the relationship between two quantitative variables by fitting a straight line through the observed data points. It assumes that, on average, one variable changes at a constant rate with respect to the other.

It is used for prediction and forecasting problems where the goal is to estimate a numeric value, such as estimating a salary from years of experience, predicting a house price from its size, or forecasting sales from advertising spend.

The independent variable is the input used to make a prediction. It is the value the user provides to the model, plotted on the X-axis of the regression chart.

The dependent variable is the outcome the model tries to predict. Its value is assumed to depend on the independent variable, and it is plotted on the Y-axis of the regression chart.

Simple Linear Regression assumes a linear relationship: as the independent variable increases or decreases, the dependent variable tends to change at a roughly constant rate. A scatter plot is used to visually verify this assumption before trusting the model.

The regression line is the straight line, in the form y = mx + b, that best fits the training data. It is found using Ordinary Least Squares, a method that minimizes the sum of the squared distances between each data point and the line.

Once the line is fitted, a prediction is made by plugging a new value of the independent variable into the equation to obtain an estimated value for the dependent variable.

Suppose a model learns the equation salary = 500,000 × years + 1,000,000. For someone with 10 years of experience, the model would predict a monthly salary of 500,000 × 10 + 1,000,000 = 6,000,000. This is exactly the kind of calculation performed by the model on the Application page.
