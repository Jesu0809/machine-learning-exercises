The agent-environment loop

Every step follows the same cycle, one state at a time.

State s → Agent picks action a → Environment applies step() → Reward r, next state s′ → Model learns from (s, a, r, s′)

An agent takes actions and observes how the environment responds. A numeric reward guides the learning, and the goal is to learn a policy that maximizes the expected return over time. It is the third type of machine learning: supervised learning learns from examples with a known answer, unsupervised learning finds patterns with no labels at all, and reinforcement learning learns a sequence of decisions through interaction and rewards.

The agent is the virtual robot choosing moves. The environment is the fixed 10×10 maze, its walls, its danger zones and its movement rules. The state s is the current position (row, column), with the first index at zero.

An action a moves the agent up, down, left or right. The reward r depends on what that move actually resulted in: a normal step, an attempt to leave the grid, a wall hit, a step into a danger zone, or reaching the goal (see the reward table below). A policy π is the rule that decides which action to take in each state.

A step is one action producing a new state and a reward. An episode is one attempt from the start position until the goal or a step limit is reached. An experience is the tuple (s, a, r, s′) plus a flag saying whether that step ended the episode.

Exploration tries a random action to learn something new; exploitation picks the action with the highest estimated value. The ε-greedy rule mixes both: with probability ε the agent explores, and with probability 1 - ε it exploits (even exploring can land on the best action by chance). Here ε starts at 1.0 and decays by a factor of 0.995 after every episode down to a floor of 0.05, so the agent explores a lot at first and mostly exploits once it has learned something.

The immediate reward is the result of a single transition. A penalty is simply a negative reward: a signal that a move was undesirable, whether mild (a normal step already costs something, to favor short paths) or severe (a wall hit, an off-grid attempt, or entering a danger zone). The return combines the rewards obtained from a point in time onward. The discount γ controls how much weight the future gets: a value close to 1 favors long-term reward. This project uses γ = 0.95.

V(s) is the expected return from a state if the agent follows its policy. Q(s, a) is the expected return after taking one specific action in a state and then continuing with the policy. We represent Q with a linear model: one weight per state-action pair.

After taking an action, the agent builds a target value and nudges its model toward it: target = reward + gamma * future, where future is the best Q-value predicted for the next state (or just the reward if that state ends the episode). As a worked example: with a current Q of 0, a reward of -1, γ = 0.95, an estimated future value of 10, and a learning rate α = 0.1, the target is -1 + 0.95 × 10 = 8.5, and the updated Q becomes 0 + 0.1 × (8.5 - 0) = 0.85. A small immediate cost can still lead to a good long-term decision.

A scikit-learn SGDRegressor plays the role of the Q function: it predicts a numeric Q(s, a) and learns from one example at a time. Our own code defines the environment: the actions, the rewards, the exploration rule and the target formula. predict() estimates the four action values for a state; partial_fit() learns from a single observed transition without restarting the model. Every state-action pair is encoded as a one-hot vector with 100 positions (one per maze cell) times 4 actions, 400 features in total, with no intercept and no penalty term so that each weight keeps its own meaning as a Q-value.

Danger zone: a penalty, not a wall

Unlike a wall, a danger zone does not block the agent: the move still happens and the episode continues. It only carries a much larger penalty than a normal step, which is exactly what a negative reward, or penalty, is for — it does not stop the agent, it just makes that choice look worse during learning, so a well-trained policy routes around danger zones whenever a safer path of similar length exists.
