Unsupervised Machine Learning: Concepts

The ideas behind clustering and K-Means, before working through the manual simulation and the interactive application.

A type of machine learning where the data has no target variable and no labeled answer to learn from. Instead of predicting a known outcome, the algorithm looks at the inputs alone and finds patterns or structure in them. All the models used earlier in this project (Linear Regression, Logistic Regression, the Decision Tree) are supervised: they learn from a target. Clustering is unsupervised: there is no target at all.

Clustering groups observations so that records inside the same group are similar to each other, and different from records in other groups, based only on their features. Nobody tells the algorithm what the groups should mean; it discovers them from how the points are distributed in space.

K-Means splits the data into k groups by repeating four steps: place k centroids, measure the distance from every record to each centroid, assign each record to its nearest centroid, and move each centroid to the average position of the records just assigned to it. Those four steps are repeated until the centroids stop moving by much, which means the clusters have settled.

A centroid is the center point of a cluster: the average of every feature over all the records currently assigned to it. It is not necessarily one of the real records, just the point that best summarizes where that group sits. Every record is labeled by whichever centroid it is closest to, using the Euclidean distance.

A single pass of assign-then-recompute is rarely enough, because moving the centroids changes which records are now closest to them. Each iteration usually reassigns a few borderline records and nudges the centroids a little further toward their true center. The algorithm converges when an iteration no longer changes any assignment, or when a fixed number of iterations has been reached.

K-Means needs k to be chosen beforehand. One common way is the elbow method: fit the model for several values of k and plot the inertia (how tight the clusters are) against k. Inertia always drops as k grows, but past a certain point it stops dropping by much, forming an elbow in the curve. That point is a reasonable choice for k. The Application page in this project uses this method to justify k = 3.
