Logistic Regression: Concepts

The ideas needed to understand Binary Logistic Regression before using the interactive classifier on the Application page.

A supervised algorithm that estimates the probability that an observation belongs to a class. It builds a linear combination of the inputs and passes it through the sigmoid function, so the output is always a number between 0 and 1.

Although it fits a line internally, its output is a probability that is turned into a category by comparing it with a threshold. It predicts a discrete class, not a continuous value, so it is a classifier.

Assigning each observation to one of exactly two classes, usually coded as 0 and 1. In this project: 0 = Low Risk (repaid on time) and 1 = High Risk (defaulted).

The input used to make the prediction. Here it is the borrower's debt-to-income ratio, measured in percent.

The value the model tries to predict: defaulted. It takes two values, 0 (the loan was repaid on time) and 1 (the borrower defaulted).

The possible values of the target variable. This model has two labels: 0 = Low Risk and 1 = High Risk. The model always returns one of them.

Before choosing a label, the model produces a probability between 0 and 1 (the sigmoid output). A value of 0.8 means the model estimates an 80% chance that the observation belongs to class 1 (High Risk).

The cut-off applied to the probability. With the default threshold of 0.5, a probability of 0.5 or more is labelled class 1, and anything below 0.5 is labelled class 0.

Linear Regression predicts a continuous number and its output has no bounds; it fits a straight line. Logistic Regression predicts a probability between 0 and 1 that is then turned into a class; it fits an S-shaped sigmoid curve.

The sigmoid function

Logistic Regression maps any real number z (the linear combination of the inputs) to a probability with p = 1 / (1 + e-z). The dashed line marks the 0.5 threshold.
